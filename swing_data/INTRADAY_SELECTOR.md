# 時刻指定の暫定選定モデル（第4段階）

当日08:15までに固定した `morning-0815-snapshots` のJSONと、そこに記録されたSHA-256と完全一致する5分足DBだけを使います。対象は `config/contest_equity_tickers.json` に明示した普通株9銘柄です。1570 ETFは勝負のルールに従って除外しています。データ欠損、8:15超過、前日売買代金1.5億円未満では**見送り**を出します。

予め固定した買い時刻7通りと売り時刻3通りを比較します。各銘柄について直近120営業日以内の完全な5分足を古い順に学習期間と確認期間へ分け、学習期間の平均損益が最も高い1組だけを選びます。確認期間の収益から算出した下側推定値と学習期間の縮小平均がともにプラスの時だけ採用します。学習7日・確認3日、合計10日以上が必要です。**10日で優位性は証明できません。** 確認期間の結果も銘柄選択に利用するため、今回の勝負で朝の予想を固定し、その後の結果を追うフォワード検証を行います。

約定価格は指定5分足の始値で近似し、往復0.20%を費用と価格ずれとして控除します。実際の成行注文はその価格で約定する保証がありません。初期資金200万円、1銘柄100万円まで、最大3銘柄、100株単位で株数を決めます。前日終値の1.2倍を資金計算に使い、寄りの価格変動に備えます。それ以上のギャップでは資金不足になり得ます。

出力は `morning-0815-snapshots` ブランチの `picks/YYYY/MM/YYYY-MM-DD.json` に朝の入力とともに追記されます。`PROVISIONAL_PICKS` は試験的な提案、`NO_TRADE` は見送りです。通知や発注は行いません。10日未満の履歴では見送りです。引け後の約定推定と勝負台帳で結果を追います。

手動実行:

```bash
python -m swing_data.intraday_selector \
  --snapshot morning.json \
  --db intraday_5m.sqlite \
  --output-dir morning-picks
```
